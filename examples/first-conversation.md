# Begin with an idea, without connecting a tool

Synthetic example from a local skill review. This illustrates one reviewing model’s response, not a guarantee across clients.

## User

“We are a two-person SaaS startup. I think shortening our signup form could help. I have never run an A/B test. Help me plan one. I don’t know our conversion rate and don’t want to connect any analytics tools.”

## Example agent response

TL;DR: We can draft the test without connecting analytics. First we need a clear outcome and basic measurement to assess feasibility.

1. **Draft question:** Does a shorter signup form help new eligible people complete signup? Keep the current form as control; specify which fields the shorter version removes. Less effort is a plausible explanation, but we have not observed that it causes your drop-off.
2. **Draft metric:** people completing signup within an agreed window / new eligible people assigned. Track errors and whether new signups still have the information needed to use the product. Keep each returning person in the same group.
3. **Small context check:** Which fields would you remove, and what have you observed people struggling with? Roughly how many new people reach signup each week, and when do you need a decision? Unknown is fine.
4. **Measurement next:** Use existing records or a manual cohort tally to count people reaching signup and how many complete within the same outcome window. Without that baseline and eligible traffic, sample and timing stay unresolved.

Next action: share the current fields and any observed signup difficulty; we can refine the treatment while measuring the baseline.
